## Claim

GPU-accelerated ANN search (FAISS-GPU or cuVS) outperforms pgvector CPU HNSW by > 10x on throughput at 10M+ blocks, at equivalent recall@10, making it the dominant optimization lever for the inference substrate at scale.

## Operationalization

Dataset: 10M-block corpus with 1536-dim float32 embeddings.
Metric: queries/sec at recall@10 = 0.95.
Baseline: pgvector HNSW on CPU (ef_search tuned for recall@10 = 0.95).
Intervention: FAISS-GPU IVF-PQ and cuVS HNSW on same machine with GPU.
Acceptance criterion: GPU ANN achieves > 10x higher queries/sec than pgvector CPU at equivalent recall.

## Null Hypothesis

pgvector CPU HNSW is within 5x of GPU ANN at 10M blocks because HNSW's graph traversal is memory-latency bound, not compute bound, and GPU parallelism doesn't help memory-latency bottlenecks.

## Experiment Spec

1. Generate 10M random 1536-dim float32 vectors (or use real block embeddings if corpus is available).
2. Build pgvector HNSW index (m=16, ef_construction=128). Tune ef_search for recall@10 = 0.95. Measure throughput.
3. Build FAISS-GPU IVF-PQ index (nlist tuned for recall@10 = 0.95). Measure throughput.
4. Build cuVS HNSW index. Measure throughput.
5. Run all three on identical 10K-query workload. Record throughput and recall@10.
6. Repeat at 1M and 100M if hardware allows.
