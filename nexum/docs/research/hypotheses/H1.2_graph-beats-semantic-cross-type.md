## Claim

Heterogeneous corpora (PDFs + structured tables + code) degrade embedding quality more than structural link quality — meaning graph traversal outperforms semantic search on cross-type queries.

## Operationalization

Dataset: mixed corpus with equal parts PDF paragraphs, table cells, and code blocks (100K blocks each).
Metric: recall@10 for cross-type queries (e.g., a natural-language question answered by a table row).
Baseline: pure semantic ANN search.
Intervention: 2-hop graph traversal from the best ANN hit.
Acceptance criterion: graph-expanded results improve recall@10 by > 15% vs. ANN alone on cross-type query set.

## Null Hypothesis

Embedding quality degrades uniformly across content types; graph traversal provides no additional recall benefit for cross-type queries.

## Experiment Spec

1. Build a 300K-block mixed corpus (100K each: PDF paragraphs, table cells, code blocks).
2. Embed all blocks with text-embedding-3-small.
3. Construct structural links (section containment) and AI links (Claude-classified semantic relationships) across types.
4. Build a 200-question cross-type eval set: questions whose ground-truth answer block is a different type than the question.
5. Evaluate: (a) ANN top-10 recall, (b) ANN top-10 + 2-hop graph expansion recall.
6. Compare recall@10 delta.

## Results

**Status:** failed (under the original 15% hybrid-vs-semantic acceptance criterion).
**Run:** 50K-block synthetic mixed-type corpus on Postgres + pgvector, 200 planted
cross-type queries, k = 10. Driver: `experiments/area1-storage-fitness/h12_retrieval_comparison.py`.
Result envelope: `experiments/area1-storage-fitness/results/h1.2_20260510T015402Z.json`.

| mode           | recall@10 | NDCG@10 | p50 ms | p99 ms |
| -------------- | --------: | ------: | -----: | -----: |
| fulltext       | 1.000     | 0.593   | 4.5    | 6.6    |
| semantic       | 0.075     | 0.034   | 1.1    | 1.5    |
| graph_only     | 0.245     | 0.140   | 0.4    | 2.0    |
| hybrid         | 0.075     | 0.034   | 2.8    | 3.8    |
| edge_semantic  | 0.765     | 0.460   | 2.0    | 2.2    |

The original criterion (hybrid recall@10 > semantic by 15%) is **refuted**: hybrid
matched semantic exactly because the planted target was almost never one hop from
the semantic top-10 — semantic at scale loses the topic in the noise floor before
the graph layer can rescue it.

The *spirit* of H1.2 — graph-derived signal beating embedding similarity on
cross-type queries — is **strongly supported** by the AGE / edge-similarity mode
introduced in PR #86: `edge_semantic` recall@10 = 0.765 vs semantic 0.075,
a 10× improvement at comparable latency. This shifts the operationalisation:
typed edges with their own embeddings appear to be the productive way to
combine structural and semantic signal, not late-stage hybrid expansion.

**Caveats** (recorded in the envelope notes):
  - Synthetic planted-cross-type generative model (controlled topics + noise),
    not a real cross-type benchmark such as BEIR/TREC. Recall ratios are
    indicative of the rank ordering of modes, not of absolute recall in
    production corpora.
  - fulltext wins trivially because each query carries a unique distinguishing
    keyword (`topic_<id>`); it is included as a calibration baseline only.
  - No AGE Cypher path was exercised here because AGE was unavailable on the
    benchmark host — `edge_semantic` was scored via the pgvector index on
    `links.edge_embedding` which is the same physical index AGE-mode queries
    fall back to in production.
