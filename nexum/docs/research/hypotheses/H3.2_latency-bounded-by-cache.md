## Claim

The latency gap between graph-resident inference and static model inference can be bounded to 20–50x (not 1000x) with a two-tier cache: hot blocks (high degree, recent access) in memory, cold blocks on disk-backed HNSW.

## Operationalization

Dataset: 1M-block corpus with Zipfian access distribution.
Metric: effective inference latency (ms per step) across cache hit rates.
Baseline: cold graph inference (no cache, every retrieval hits HNSW on disk).
Intervention: in-memory cache for top-N% blocks by degree + recency, measured at N=1%, 5%, 10%.
Acceptance criterion: at 5% cache size, effective latency is within 50x of a llama.cpp GGUF forward pass on same hardware.

## Null Hypothesis

Cache has minimal effect on inference latency because access patterns are not sufficiently Zipfian in real corpora; effective latency stays above 100x even with 10% cache.

## Experiment Spec

1. Load 1M blocks into Postgres with HNSW index.
2. Simulate 10K inference step calls with Zipfian query distribution (alpha=1.2).
3. Measure latency per step without cache.
4. Implement in-memory LRU cache keyed on block UUID. Warm with top-N% blocks by in-degree.
5. Re-run 10K inference steps. Measure latency per step at cache sizes 1%, 5%, 10%.
6. Measure llama.cpp baseline on same hardware (single forward pass, comparable model size).
7. Report latency ratio at each cache level.
