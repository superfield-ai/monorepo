# Seed intent: a simple To Do app

We want a small internal **To Do** web application. The minimum a user must be
able to do:

- **Add** a task (a short text description).
- **List** all tasks, newest first.
- **Complete** a task (mark it done so it is visually distinct from open tasks).

That is the whole scope for this experiment. No accounts, no sharing, no due
dates, no priorities — just add, list, complete. Keep it deliberately small so
we can measure how many loop turns it takes the appliance to reach a coherent
plan and a first compiling code change for this app.
