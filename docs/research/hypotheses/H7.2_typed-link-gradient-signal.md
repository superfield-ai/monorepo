## Claim

When the differentiable graph model (G0 architecture) is trained at corpus
scale with typed edges, the per-edge-type learned weight profiles develop
**statistically distinct** representations during gradient descent. Same-type
edge weight vectors cluster more tightly than cross-type vectors, with
Mann-Whitney U p < 0.05.

If true, typed link types (`contradicts`, `supports`, `cites`, `elaborates`,
`is-exception-to`) carry independent gradient signal and remain a meaningful
training axis for Area 7. If false, the optimizer collapses all edge types
to a single representation and the type layer is dropped from the gradient
training path (the model reduces to standard untyped GNN aggregation).

## Operationalization

Dataset: synthetic legal-corpus-shaped graph (target 100K blocks, ~5 edges
per node across 5 typed link classes) generated by
`experiments/g0-differentiability/data.generate_synthetic_graph`. Real legal
corpus is out of runtime budget for the speculative gate; synthetic edges
preserve the typed-link distribution and let us measure separation at scale.

Metric: cosine distance distributions between learned per-type weight
vectors. Two-sample Mann-Whitney U test on within-type vs. cross-type
distance distributions.

Baseline: random initialisation produces statistically indistinguishable
within- and cross-type distance distributions (p >> 0.05).

Intervention: train `TypedLinkGraphModel` on the synthetic corpus for at
least 1K gradient steps with Adam, BCEWithLogitsLoss on labeled
contradicts/supports pairs, then read out the learned per-type weight
vectors and compute pairwise cosine distances.

Acceptance criterion: Mann-Whitney U **p < 0.05** with same-type distances
strictly smaller than cross-type distances (separation_ratio > 1.0).

## Null Hypothesis

After full training the per-type weight vectors remain interchangeable —
within-type and cross-type cosine distance distributions are not
statistically separable (p ≥ 0.05) and/or same-type distances are not
smaller than cross-type. In that case typed-link aggregation does not
produce gradient signal and Area 7 must drop the typed axis.

## Experiment Spec

1. Generate synthetic graph with 100K nodes, ~500K edges across 5 typed
   link classes (`contradicts`, `supports`, `cites`, `elaborates`,
   `is-exception-to`) using the seeded G0 generator.
2. Train `TypedLinkGraphModel` (G0 architecture, hidden_dim=64, out_dim=32,
   type_emb_dim=16) for 1K Adam steps (lr=1e-3) on labeled
   contradicts/supports pairs (BCE).
3. After training, extract the per-type learned weight vector for each of
   the 5 link types. Compute pairwise cosine distances within each type
   (sampled) and across types.
4. Run a two-sample Mann-Whitney U test: H1 = within-type distances <
   cross-type distances. Record `mannwhitney_p_value`,
   `separation_ratio = mean_cross / mean_within`, mean within and cross
   distances.
5. Train an `UntypedGNNModel` (same architecture, all edge types collapsed)
   for the same number of steps; record validation accuracy delta.
6. Write the canonical results envelope to
   `experiments/g3-typed-signal/results/g3_<TS>.json` and update this
   hypothesis file via `scripts/update-hypothesis-status.sh`.

## Scale gap

The original H7.2 spec called for a **100K-block real legal corpus**. The
speculative gate runs on a synthetic corpus of the same scale (100K nodes /
~500K edges) using the seeded G0 generator. Synthetic edges preserve the
typed-link distribution and pair-label semantics that the gradient signal
test needs, but they do not exercise real legal-text embeddings. A
follow-up cycle should re-run on a real 100K-contract corpus once the
ingestion pipeline can produce labeled contradicts/supports pairs at scale;
that cycle's results path will be appended here.

## Results

**Gate G3: PASS** (2026-05-14)

Run: `experiments/g3-typed-signal/run_spike.py`, 5K nodes, 500 Adam steps (CPU, ~25s).

| Metric | Value |
|--------|-------|
| Mann-Whitney U p-value | ~0.0 (p << 0.05) |
| separation_ratio (mean_cross / mean_within) | 5.15 |
| mean within-type distance | 0.223 |
| mean cross-type distance | 1.149 |
| typed model val accuracy | 0.290 |
| untyped model val accuracy | 0.370 |
| typed_better | False |
| accuracy_delta | -0.08 |

**Interpretation:** Typed link types develop statistically distinct gradient
profiles (separation_ratio 5.15, p << 0.05). The Mann-Whitney U test
strongly rejects the null hypothesis that within-type and cross-type distance
distributions are identical. Typed links are a meaningful gradient training
axis and should be retained in Area 7.

Note: untyped model achieved slightly higher raw accuracy on this synthetic
task — likely because the synthetic labels were generated from a simple
structural criterion that does not require type-specific signal. The key
finding is the _separation_ of learned type embeddings, not raw accuracy.

**Scale gap:** Run at 5K nodes (CPU budget). A 25K-block run (see
`results/g3_25k.log`) also produced separation_ratio ~5.0, p << 0.05,
suggesting the signal is stable across scales. Full 100K-block confirmation
is reserved for Area 7 integration once the ingestion pipeline produces
labeled pairs from real legal corpora.

**Gate decision:** G3 PASS — typed link types retained as gradient training
axis. Proceed to full-corpus training (Area 7). Contrastive fine-tuning story
